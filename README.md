# Composer Review for Claude Code: feedback

Bug reports, ideas and questions for **Composer Review for Claude Code**, the VS Code extension and Claude Code plugin that let you review Claude's changes hunk by hunk.

## How to report

- **From VS Code:** run **Composer: Report a Problem** (Command Palette, or the `...` menu of the Composer view). It fills in your environment (versions, OS, Doctor results, recent log lines) and opens a prefilled issue here; you review it and click **Submit**.
- **From Claude Code:** ask Claude to "report this Composer bug". Claude describes what happened from your conversation, Composer adds the environment, and the same prefilled page opens for you to submit.
- **By hand:** [open an issue](../../issues/new/choose).

Nothing is sent until you click Submit. Reports never contain your files, diffs, prompts or absolute paths; check the preview before you submit.
